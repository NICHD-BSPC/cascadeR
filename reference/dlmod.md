# Download button module

Download button module

## Usage

``` r
downloadPlotUI(id)

downloadPlotServer(id, outplot, plot_type, direction = NULL)
```

## Arguments

- id:

  Input id

- outplot:

  reactive plot handle

- plot_type:

  reactive/static value used for output filename

- direction:

  direction of phylogenetic tree

## Value

Shiny UI & server element for the plot download button module
